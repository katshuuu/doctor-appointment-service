# Сервис записи к врачу

Консольное приложение для онлайн-записи пациентов на прием к врачу.
После ПР3 приложение построено на объектной модели: сущности предметной
области — классы, а не словари, и объекты взаимодействуют друг с другом
напрямую.

## Возможности

- просмотр и поиск врачей;
- отбор врачей по специальности;
- проверка доступности времени приема;
- оформление записи на прием;
- отмена записи (без удаления — меняется состояние записи);
- статистика количества активных записей по врачам.

## Основные классы

### `Doctor` (`entities/doctor.py`) — Врач

Атрибуты: `id`, `name`, `specialty`.
Методы: `__init__()`, `__str__()`, `from_data()` (`@classmethod` —
создаёт врача из словаря, например при загрузке из JSON).

### `Patient` (`entities/patient.py`) — Пациент

Атрибуты: `name`, `age`.
Методы: `__init__()`, `__str__()`, `is_minor()` — проверка
несовершеннолетия конкретного пациента; `is_minor_age()`
(`@staticmethod` — проверка по значению возраста без создания объекта,
например `Patient.is_minor_age(16)`); `from_data()` (`@classmethod`).

### `Appointment` (`entities/appointment.py`) — Запись на прием

Атрибуты: `id`, `doctor` (объект `Doctor`), `patient` (объект
`Patient`), `appointment_date`, `appointment_time`, `is_cancelled`.
Методы: `__init__()`, `cancel()` — отмена записи изменением состояния,
без удаления объекта из коллекции; `__str__()` — отражает текущее
состояние («активна» / «отменена»); `from_data()` (`@classmethod` —
принимает словарь из JSON и уже найденный объект `Doctor`, создаёт
внутри себя объект `Patient`).

## Взаимодействие объектов

Объект `Appointment` не хранит `doctor_id`/имя пациента отдельными
полями — он хранит ссылку на реальный объект `Doctor` и владеет
объектом `Patient`:

```
appointment
 ├── doctor  → Doctor
 └── patient → Patient
```

Благодаря этому данные связанных объектов доступны напрямую:
`appointment.doctor.name`, `appointment.doctor.specialty`,
`appointment.patient.age`. Отмена записи выполняется вызовом метода
самого объекта — `appointment.cancel()`, а не функцией, удаляющей
элемент из списка: запись остаётся в коллекции, но перестаёт
блокировать время (`appointments.is_slot_available()` учитывает только
не отменённые записи).

## Структура проекта

- `main.py` — точка запуска и меню; не хранит и не обрабатывает
  словари предметной области — только вызывает функции модулей и
  методы объектов;
- `doctors.py` — функции для `list[Doctor]`: поиск, фильтрация,
  сортировка, вывод;
- `appointments.py` — функции для `list[Appointment]`: проверка
  доступности, создание, отмена, статистика, вывод;
- `storage.py` — преобразование JSON ↔ объекты (`load_doctors`,
  `save_doctors`, `load_appointments`, `save_appointments`);
- `utils.py` — вспомогательные функции ввода;
- `entities/` — классы предметной области:
  - `entities/doctor.py` — `Doctor`;
  - `entities/patient.py` — `Patient`;
  - `entities/specialty.py` — справочник специальностей;
  - `entities/appointment.py` — `Appointment`;
  - `entities/__init__.py` — реэкспорт классов
    (`from entities import Doctor, Patient, Appointment`);
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты (25 тестов).

## Хранение данных

Данные по-прежнему хранятся в JSON. Связанные объекты сохраняются как
идентификаторы, а не вложенные структуры: у записи в
`appointments.json` есть поле `doctor_id`, а не вложенный объект врача.
При загрузке `storage.load_appointments()` находит объект `Doctor` по
`doctor_id` в уже загруженной коллекции `doctors` и передаёт его в
`Appointment.from_data()`. Если врач с таким `id` не найден — запись
пропускается с предупреждением, а не создаётся как повреждённый
объект.

Пример записи в `data/appointments.json`:
```json
{
  "id": 1,
  "doctor_id": 1,
  "patient_name": "Иванов Иван Иванович",
  "patient_age": 34,
  "appointment_date": "2026-09-15",
  "appointment_time": "10:30:00",
  "is_cancelled": false
}
```

## Требования

- Python 3.x;
- pytest;
- flake8;
- mypy;
- autopep8 (проверка форматирования).

Установка зависимостей:

    pip install -r requirements.txt

## Запуск программы

    python main.py

## Запуск тестов

Обычный режим:

    pytest

Расширенный режим (список каждого теста):

    pytest -v

Тесты проверяют: создание и строковое представление объектов `Doctor`,
`Patient`, `Appointment`; методы `is_minor()` / `is_minor_age()`;
`cancel()` и то, что отменённая запись не удаляется, но освобождает
время; `from_data()` всех трёх классов; поиск, фильтрацию, сортировку
врачей; статистику по активным записям; обработку `ValueError` при
повторной записи на занятое время и при отмене несуществующей записи.

## Проверка качества кода

    flake8 .
    mypy . --exclude tests
    autopep8 --diff --recursive .
