# Сервис записи к врачу

## Назначение
Приложение предназначено для онлайн-записи пациентов на прием к врачу.
Сервис решает задачу упрощения выбора специалиста, свободного времени
приема и подтверждения записи без необходимости личного обращения
в регистратуру.

## Целевая аудитория
Пациенты медицинских клиник, желающие самостоятельно записаться на прием,
а также администраторы клиники, контролирующие расписание врачей.

## Предметная область
Организация записи пациентов на прием к врачам различных специальностей:
ведение расписания врачей, выбор специальности, оформление и подтверждение
записи на определенную дату и время.

## Основные сущности
- Пациент
- Врач
- Специальность
- Запись (на прием)

## Основные функции
- регистрация и хранение данных пациента;
- выбор врача по специальности;
- проверка доступности времени приема;
- оформление записи на прием;
- отображение статуса записи (подтверждена / время занято).

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
